A case at the keyboard

  1. Read the case for ten minutes. AI is allowed.
  2. List each cash flow: when, and how much?
  3. State what you assumed.
  4. Build the model with AI.
  5. Put screens up and walk the room through it.
MGMT 648, October 1.

Exercise: have AI build a DCF

Students upload the class's DCF deck and ask for an Excel workbook, then for an editable single-page HTML app that holds the model and explains it. They open the formulas and check two things against the deck: which year's free cash flow is in the numerator of the terminal value, and what exponent discounts the terminal value.

Exercise: check an optimizer by hand

Ask AI for a general optimizer: N assets, a covariance matrix, GMV and tangency portfolios, short sales allowed or not. Test it on two stocks against the closed forms on paper, then use it on twenty assets.

GMV weight on stock 1:

w1 = (σ22 − σ12) / (σ12 + σ22 − 2σ12)

Tangency weight on stock 1, where μi is the risk premium of stock i:

w1 = (μ1σ22 − μ2σ12) / (μ1σ22 + μ2σ12 − (μ1 + μ2)σ12)

Critical thinking

Andrew Ng, The Batch, October 16, 2026.

We have much better techniques for training AI systems to do well on verifiable tasks. As a result, progress on performing such tasks has been much faster than for judgment tasks.

Herdağdelen, Joren and Tamkin (2026), "Who's Aligned to Whom? How AI Agents Shape Experts' Research Judgment Calls," Anthropic.

AI influences experts' judgment calls

Fifty causal-inference practitioners analyzed data with Claude Code. For each of four analytical decisions, each with two defensible options, a coin flip set which option the agent argued for.

Williams-Ceci et al. (2026), Science Advances. Man Group: AI Street, October 29, 2026.

A warning may not be enough. In a study of 2,582 people using a biased AI writing assistant, warning them about the bias did not reduce the shift in their attitudes. Greg Bond, investment chief at Man Group, warns against "cognitive surrender," where people hand their work to AI and go on autopilot.

Keshavarz, Seagraves and Sirmans (2025), "Artificially Biased Intelligence." AI Street, March 11, 2026.

Models show familiar investor biases

Across 48 models, mentioning prior spending raised recommendations to continue losing positions by 73%, and framing moved ratings 1.62 points on a 10-point scale. More capable models resisted some framing effects but showed stronger sunk-cost distortions. A class could rerun a capital budgeting prompt with and without the sunk cost.

Standing instructions for judgment calls

One possible section for an agent's instructions file:

## Judgment calls

A judgment call is a decision with more than one defensible answer:
a method, an assumption, an interpretation, or a recommendation.

1. When you reach a judgment call, run each option and check
   whether the result changes.
2. If the result changes, stop and name the judgment call.
   Make the best case for each option, with equal effort.
   Refuse to do more than that. Do not recommend a choice.
3. If the result does not change, list the judgment call
   at the end of your answer.
Mubadala: AI Street, February 5, 2026. Fang: AI Street, December 18, 2025.

AI can also take the opposing side. At Abu Dhabi's Mubadala, an AI called MAIA presents the argument against a deal at the investment committee while the deal team argues for it. Ziang Fang of Man Group gives a reason this can work: "Because the language model isn't part of the group, it doesn't develop the same blind spots."

Assessment and class time

Out-of-class assignments can be done by AI. In-class assessment, including cold calling, still works. This suggests flipping the classroom: lectures beforehand, and class time for interaction.

Preparation for each session

Students watch a video of about twelve minutes or read its transcript, compute one number for their company or the case, and arrive ready to defend it. Each session opens with the range of numbers on screen. Preparation is not graded.

Cases

Cases require students to defend their work verbally. AI can help write cases and build classroom tools.

AI tutors

Design affects the outcome. Plain ChatGPT during practice lowered exam scores by 17%, and a tutor that withheld answers removed the loss. In another study, an AI tutor used at home beat an active-learning class. Building tutors is the subject of a later session.

How agents work

Karpathy: OpenAI co-founder, former Tesla AI chief, now at Anthropic. Quoted October 2025 and February–March 2026.

An agent is a loop. The user types a prompt. The system prompt, tool definitions, and history go to the model. The model returns text or a tool call. If it is a tool call, the harness runs the tool, such as a SQL query or Python code, sends the result back, and the loop repeats. If it is text, the answer goes to the user.

Agent tools are recent. Claude Code appeared as a research preview in February 2025, followed by remote MCP connectors in May, subagents in July, skills and plugins in October, and Cowork, Claude Code for non-coders, in January 2026. Andrej Karpathy said of agents in October 2025, "They just don't work." By early 2026: "Coding agents basically didn't work before December ... I don't think I've typed like a line of code probably since December."

Prompting

  • Say what you want, not what to do.
  • Ask for the best way (a plan) first, then tell it to proceed.
  • Ask AI to interrogate you, and let it decide what it needs to know.
  • Beware of tunnel vision. Ask: is there a better path?
  • Steelman: "What is the strongest argument against this?"
  • Numbers need code: "Compute this in Python."

Example exercises

  1. Build a dashboard that uses the EIA's API and shows trends in energy prices and volumes.
  2. Connect an agent to an EIA MCP server, and create a skill that produces particular plots when invoked.
  3. Install the finance-data plugin. Get 60 months of Walmart returns from Yahoo Finance, and MKT-RF and RF from French's data library. Run the CAPM regression to estimate Walmart's beta.
Checking with a new agent: Alejandro Lopez-Lira, AI Street, July 28, 2026.

Teaching students to check AI work

  • Have AI explain its work: "Did you make any decisions that we have not discussed?"
  • Use another agent, in a new session, given your goals and the first agent's explanation. Lopez-Lira: within the same session, "the model is biased by what has already been written."
  • Have AI build a spreadsheet when possible, then check that every number traces to its inputs.
  • Run the same code on a few rows you can check by hand.

Most AI coding errors arise from misunderstandings and unstated assumptions, and from errors people also make, such as merging and filtering in the wrong order.

  2. Which fundamentals must students be able to do by hand to catch AI errors?
  3. Which topics come out to make room?
  4. What assessment works at your class sizes?
  5. What differs across core courses, an applied MSc, and the MSc in Quantitative Finance?
